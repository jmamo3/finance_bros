# Financial Advisor — MCP Powered

An AI-powered personal financial advisor built with Claude, MCP, and real financial APIs.

## What it does
- Real-time stock prices and company fundamentals via Alpha Vantage
- Reddit sentiment analysis for any ticker
- Personal bank data via Plaid (sandbox)
- Personalized advice based on your risk tolerance, goals, and income

## Tech Stack
- **AI**: Claude (claude-sonnet-4-6) via Anthropic API
- **MCP**: FastMCP server exposing 5 financial tools
- **Backend**: FastAPI
- **Frontend**: React
- **APIs**: Alpha Vantage, Plaid, Reddit RSS
